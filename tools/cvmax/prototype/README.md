# CvMax 可交互原型

> 状态更新：这是旧版侧栏交互原型，仅保留为历史验证样本。新版一期有 Atoll Web 与外部 AI + Skill 两个入口，内部 Agent 统一执行，不把资料补充或故障场景做成独立功能导航。当前产品范围见 [统一设计](../README.md)。本轮未修改原型行为。

基于用户选定的第 1 张图：招聘申请页 + 右侧助手。所有数据、登录、连接和上传回执均为本地模拟，不连接 Atoll、真实招聘站或浏览器插件，也没有最终提交动作。

## 体验入口

本机预览：http://127.0.0.1:4173/

顶部切换四个体验场景：

- 资料补充：填写薪资、异地办公意愿 → 核验 → 待用户检查提交。
- 连接修复：助手检查 → 用户开启演示连接 → 自动核验并继续填写。
- 登录继续：用户在模拟申请页登录 → 助手确认账号 → 自动继续。错误账号被拦截，主动暂停不会被登录解除。
- 停止接管：在上传期间停止 → 最多 2 秒只读核对 → 结果未知时明确标记 → 用户修正学校 → 核验学校 → 用户查看附件回执 → 保持停止并交还用户检查。

重置场景会创建新的演示运行并清除当前场景输入。切换场景同样重置，不代表生产产品中的恢复操作。

## 实现边界

React + Vite，纯应用层状态机位于 `src/flow.mjs`；UI 位于 `src/App.jsx`。本次所有文件位于 `tools/cvmax/`，没有修改 Atoll 核心及其依赖。原型状态保存在当前浏览器 localStorage；损坏的记录回退到初始状态。执行中刷新恢复为暂停，停止记录不会自动解除。

异步演示事件携带运行代次，停止、暂停和重置会令旧回调失效。核验中用户修改字段会取消原完成判定。`stopped` 与只读核验分开，允许核验而不恢复自动填写。

经验条目、18/20 项计数是演示文案；本页仅展现部分字段，并非真实站点覆盖率。保存选项仅演示本地偏好，尚无跨申请答案复用、真实经验学习或自进化。尚未实现岗位推荐/批量授权入口、MCP 服务、浏览器扩展及真实登录检测。此原型用于评审单份申请中的交互，不代表业务已经上线。

## 验证

`npm test`：10 项状态规则测试。`npm run build`：生产构建。

已通过 Codex 内置浏览器实际操作验证四个场景、错误答案、错误账号、主动暂停后登录、停止后刷新、学校错误、附件结果未知和只读核验。详见 `design-qa.md`。

本地开发：`npm run dev -- --host 127.0.0.1 --port 4173 --strictPort`。
