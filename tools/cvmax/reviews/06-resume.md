# 用户06：隔夜恢复

仅依据 PRODUCT-DESIGN.md（下称 P）与 USER-JOURNEYS.md（下称 J）推演；未运行产品或测试。

## 六步推演

1. 昨天填到学校选择时合盖；我不知道最后一次输入是否保存。
2. 今天重启浏览器，原 tab 已关闭。我从历史看到“等待恢复”，希望助手自己重开岗位。
3. 点击继续，先看短概览：“核对页面 → 选择资料 → 恢复填写 → 检查提交”；当前只展开“正在核对页面”。
4. 助手重开并确认同一申请，发现网页为空。告知本地任务、确认答案仍在，但网站未保留填写内容；昨天的完成数不能代表今天页面。
5. 简历已更新。助手展示版本日期及变更摘要，我选择新资料；助手重算、补填并核验，只问无法恢复的答案。
6. 完成则停在提交前交我复核；预算耗尽则保留结果，明确需要我选择追加额度、手动完成或结束。

## 证据问题

1. **P1｜保存承诺容易被误读。** J89“已完成18项”、J91“草稿是否可用”、P98/102持久记录，未规定重启前后的计数口径。触发：网页空了仍显示18项，我以为资料丢失或恢复完成。改善：并列“上次已验证／当前待核验”，区分本地资料、任务答案与网站草稿；未留存的手填内容明确不可恢复。验收：空白页不沿用历史通过数，不声称网站已保存。

2. **P1｜恢复责任未落到用户动作。** P206要求重绑确认上下文，J93/125要求重开核验，未明确谁确认。触发：tab 已丢，我被要求找链接、重述岗位。改善：助手从记录重开并核验，只有登录或身份歧义交给我；显示“正在由助手核对”。验收：岗位唯一且无需登录时，一次继续直达核验，无额外确认。

3. **P1｜换简历影响不够可见。** J95提供两版本选择，P154禁止静默改写。触发：我不知新附件是否也更新、前页是否需重填。改善：选择处列版本日期、附件和受影响项；选择后助手完成核对。验收：旧资料默认保留，选新后报告附件及前页重验状态。

4. **P1｜恢复可能重置重试预算。** P215限定每 run 预算，J115又将恢复称为一次 Run。触发：隔夜恢复不断得到新额度，“停止”后能否自动继续不明。改善：恢复显示累计消耗与剩余额度，追加量明确；终止后不自动恢复。验收：重启不刷新额度；耗尽无新写入；停止后登录也不续跑。

## 渐进引导对话

助手：“概览：核对页面、选择资料、恢复填写、检查提交。现在由我重开并核对昨天的申请。”

助手：“网站未保留草稿。本地确认资料和答案仍在；网页手填且未留存的内容无法恢复。你有新版简历，已列出差异。继续原资料，还是使用新版？”

用户：“新版。”

助手：“正在用新版补填并核验。你可随时暂停或结束；完成后由你检查并提交。”
