# 用户09：越学越错的担心

纯设计推演，非实测。已有证据、候选门槛、隔离和回退；关注其可理解性。核心不动。

路径（6步）：
1. 首次学校搜索失败，其余独立字段自动填完。
2. 我手动选对后重验；学的是校名还是方法？
3. 第二次同站同指纹，候选验证成功，满足门槛后升级。
4. 我查看成功依据。
5. 第三次改版错填；纠正后旧版本隔离，但页面修好了吗？
6. 能力或预算到限，我需要知道成果和谁继续。

证据问题：
- P1｜tools/cvmax/PRODUCT-DESIGN.md:72、187；tools/cvmax/USER-JOURNEYS.md:140。简短“已学会”与候选阶段容易混淆。改善：概览写“学校选择方法待验证”，展开显示适用范围、两次结果及选中状态证据，明确不把校名当通用答案。验收：一次成功不宣称学会；两次证据可追溯且不暗示永远正确。
- P1｜tools/cvmax/PRODUCT-DESIGN.md:66、190。已有撤销学习和局部纠正，但撤销影响哪些版本、以后复用、当前页面及资料未解释。改善：执行后给范围收据；自动重验受影响字段，存在冲突时才请用户决定。验收：撤销后明确哪些经验仍生效，不能把禁用规则说成已修复网页。
- P1｜tools/cvmax/PRODUCT-DESIGN.md:188；tools/cvmax/USER-JOURNEYS.md:140。改版会重识别，但错填后状态未具体呈现。改善：显示“旧方法已停用，学校待重验”，可核验且无冲突的修复直接做。验收：各入口同步，未经重验不显示完成。
- P2｜tools/cvmax/PRODUCT-DESIGN.md:196、215。已有手动交接及追加预算，仍需区分“能力不支持”和“本轮次数用完”。改善：前者引导手填，后者说明新增额度后可尝试什么；保留成果并标明谁继续。验收：能力边界不靠追加预算解决，预算耗尽不自动续跑。
