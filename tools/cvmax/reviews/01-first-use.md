# 首次求职用户：首次使用情境推演

角色：非技术背景、未安装 Atoll。仅依据设计推演，未运行或实际体验软件。下文 P 指 PRODUCT-DESIGN.md，J 指 USER-JOURNEYS.md，均在 tools/cvmax/。

## 六步推演

1. 我想填第一份申请。【规定】首发只负责填写及核验，最后由我提交（P17）。【推测】安装前未必能看到这一边界。
2. 我下载安装包。【规定】包内有扩展、服务、诊断，复用既有 Atoll/agent（P233）。【推测】我没有 Atoll，无法判断下一步是装别的软件还是等待。
3. 向导报告连接失败。【规定】检测多个组件并提供具体问题与重试（P27–29）。【推测】若同时列出频道、MCP、agent 错误，我不知道先修哪个。
4. 我导入扫描版简历。【规定】解析失败能手动录入（P30）。【推测】整张资料表可能突然交给我，像重新写一遍简历。
5. 我确认联系方式、经历与附件。【规定】确认后才能自动填写，未知事实保留 unknown（P30–31）。【推测】没有最小就绪标准，我会纠结是否必须补全所有偏好。
6. 我首次打开申请页。【规定】点击一次后填写，缺失信息集中问，最终复核前停止（J32–36）。【推测】若准备未完，入口如何接回当前一步、如何保留岗位尚未规定。

## 高价值问题

**1｜P1：未安装 Atoll 的用户没有明确出口。** 依据 P27、233，J31–33。触发：首次检测找不到节点。我困惑“你在帮我安装，还是等我操作？”改善：先判定是否支持从零安装；不支持时明确“申请尚未开始”，保存入口，给唯一受支持配置入口及“稍后继续”；不得循环重试。验收：空白环境出现明确范围、当前负责人和恢复条件，不误报已准备好。

**2｜P1：连接修复没有渐进交接契约。** 依据 P27–29、58，J105。触发：本地服务未启动引发多项失败。我困惑错误是否都得自己解决。改善：按依赖诊断，只概览至多三步；能自动修复则告知后执行，仅展开当前用户动作；成功重检才推进，失败保留步骤并给暂停出口。验收：同时三项失败只出现一个主操作，用户未完成时不展示后续操作说明。

**3｜P2：解析失败的兜底仍可能要求整份重填。** 依据 P30–31、61，J102、109。触发：扫描件解析失败。我困惑是否必须补完所有资料才能开始。改善：保留附件与已提取草稿，概览“确认基本资料→打开申请→按需补充”；当前只收最少必要信息，标明其余可稍后补。验收：失败不清空成果、不重复上传；准备就绪条件可见，用户完成当前组后才展开下一组。

## 渐进对话示例

助手：“连接未完成，申请尚未开始。接下来：检查服务→完成连接→导入简历。我先检查服务。”

助手检查后：“服务正常，但还没安装 Atoll。此安装包不包含它。现在请打开安装指引完成安装；完成后点‘重新检查’，我会接着配置连接。也可稍后继续。”

【等待用户完成，不展开简历导入步骤；复检通过后再告知下一步。】
