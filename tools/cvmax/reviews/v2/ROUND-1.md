# CvMax v2.1 十角色首轮设计模拟

日期：2026-09-05  
方法：10 个独立 Agent 角色分别只读检查设计规范与可交互原型。属于产品设计推演，不是技术可行性或真实插件验收。

| # | 角色 | 主路径 | 首轮结论 | 最高问题 |
|---|---|---|---|---|
| 1 | 首次安装、一般技术 | 安装→连接失败→恢复/退出 | 未通过 | 停止可被旧操作复活；doctor/卸载断链 |
| 2 | 只用 Web | 上传→单链接→缺项→完成 | 未通过 | 核心路径为静态展示，缺少可信任务对象 |
| 3 | 外部 AI 熟练用户 | Skill→委托→Web 回答→AI 查询 | 未通过 | 双入口切换重复；同一 question/revision 不可验证 |
| 4 | 当前页快填 | 识别当前页→保留已有值→登录→完成 | 未通过 | 正常完成不可达；目标 tab 未确认 |
| 5 | 多岗位用户 | 8 链接→串行→跳过→汇总 | 未通过 | 当前岗位完成被表达为整个批次结束 |
| 6 | 登录/验证码谨慎用户 | 登录→错账号→核验→关闭恢复 | 未通过 | 用户“已登录”被直接当成核验事实；恢复失真 |
| 7 | 两项资料缺失 | 逐项回答→跨入口冲突→部分完成 | 未通过 | 一项答案后错误完成；没有答案作用域/冲突回执 |
| 8 | 敏感资料谨慎用户 | 授权→资料→停止→卸载 | 未通过 | “仅你可见”等承诺过宽；数据生命周期缺失 |
| 9 | 键盘与读屏用户 | 安装→任务→暂停→完成 | 未通过 | 状态变化焦点丢失；假输入不可编辑 |
| 10 | 页面改版与经验纠正 | 经验复用→漂移→隔离→纠正 | 未通过 | 经验只有文案，没有降级与纠正闭环 |

## 汇总与修订决策

首轮共识不是视觉问题，而是权威状态没有贯穿所有原型表面。冻结前统一修订：

1. 停止旧 run 永不复活；旧 CTA 移除，停止结果保留已完成和未知效果。
2. 安装改为三个阶段，外部 AI 明确可选；新增配对对象、站点权限、失败、复查、演练和卸载回执。
3. 单岗位增加登录→核验→缺项→回答→复核→待检查的可达链；`ready_for_review` 不等于网站已提交。
4. 批次拆分 Task 与 Application 状态，跳过/完成推进索引，全部终态后才汇总。
5. 补齐资料生命周期、访问主体、权限撤销和招聘网站草稿遗留。
6. 冻结经验 candidate/reusable/degraded/quarantined/retired 模型，以及页面变化与用户纠正流程。
7. 状态变化管理焦点；缺项使用真实输入、questionId、revision 和作用范围。

以上修订曾进入 v2.2 候选；随后用户指出其仍采用传统 Web 表单和操作台思路。本轮报告保留为证据，但基于该 UI 假设的复验已中止。新的 v2.2 候选以 AI 对话为唯一业务交互，远端 Web 只读展示，需重新执行角色复验。
